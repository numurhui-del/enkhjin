# Энхжинд зориулсан төрсөн өдрийн 3D сюрприз

Утасны browser дээр шууд нээгдэх жижиг 3D тоглоом. Энхжин өөрийн character-ийг хуруугаараа удирдан бялуу барьсан чам дээр очиход хоёулаа сандал дээр суугаад, camera тэнгэр рүү харж, салют буудна. Тэгээд "Төрсөн өдрийн мэнд, Энхжин" гэсэн бичгийг салютын очоор тэнгэрт бичнэ. Бичиг сарнисны дараа "Дахин үзэх" товч гарч, дарахад салютаар дахин бичнэ.

Multiplayer, server, database, login огт байхгүй. Зөвхөн static файлууд.

## 1. Бүтэц

```
Enkhjin/
├── index.html            HTML, Three.js-ийг CDN-ээс ачаална
├── style.css             Дэлхий үүсэх хэсэг, joystick, ярианы цонх
├── README.md
├── src/
│   ├── config.js         ⭐ Текст, өнгө, үс, хувцас, байрлал, дуу. Ихэнхийг эндээс өөрчилнө
│   ├── story.js          ⭐ Харилцан яриа: Мөнх-Очирын үг, Энхжингийн хоёр хариулт
│   ├── dialogue.js       Тоглоом шиг ярианы цонх, сонголтын товч
│   ├── main.js           Бүгдийг холбож, үндсэн loop ажиллуулна. triggerEnding() энд
│   ├── character.js      Chibi character (толгой, бие, гар, хөл, нүүр, үс, анимэйшн)
│   ├── cake.js           Төрсөн өдрийн бялуу
│   ├── player.js         Энхжингийн хөдөлгөөн, мөргөлдөөн
│   ├── controls.js       Touch joystick + WASD / сумтай товч
│   ├── camera.js         Дагах camera ба cinematic шилжилт
│   ├── environment.js    Зүлэг, мод, цэцэг, чулуун зам, сандал, гэрэл, сар, од
│   ├── fireworks.js      Салютын particle систем
│   ├── fireworkText.js   Тэнгэрт салютаар бичиг бичих
│   ├── ending.js         Төгсгөлийн cinematic дараалал
│   ├── effects.js        Зүрхэн тэмдэг, хөвөх зүрхнүүд, гэрлийн texture
│   ├── audio.js          Дууны систем (файл эсвэл синтез дуу)
│   ├── ui.js             HTML давхаргууд
│   └── utils.js          Туслах функцууд
└── assets/
    ├── audio/            Өөрийн дууны файлууд (README.txt дотор нэр, формат бий)
    ├── models/           Одоогоор хоосон (доорх 6 дугаар хэсгийг үз)
    ├── textures/         Одоогоор хоосон
    └── fonts/            Одоогоор хоосон (Google Fonts ашиглаж байгаа)
```

Бүх 3D объект код дотор үүсдэг тул ямар ч model, зураг файл шаардлагагүй. Шууд ажиллана.

## 2. Local дээр ажиллуулах

ES module ашиглаж байгаа тул `index.html`-ийг давхар товшиж нээвэл ажиллахгүй. Жижиг local server хэрэгтэй.

Python байгаа бол project хавтас дотроо:

```bash
python -m http.server 8080
```

эсвэл Node.js байгаа бол:

```bash
npx serve .
```

Дараа нь browser дээр `http://localhost:8080` нээнэ.

Компьютер дээр WASD эсвэл сумтай товчоор алхна. Төгсгөл нь зөвхөн Энхжин өөрөө алхаж Мөнх-Очир дээр очиход л эхэлнэ.

### Утсан дээрээ local-аар турших

Утас, компьютер хоёр нэг WiFi-д холбогдсон байх ёстой. Компьютерийн IP хаягаа олоод (Windows дээр `ipconfig` гэж бичихэд IPv4 Address), утсандаа `http://192.168.x.x:8080` гэж нээнэ.

## 3. Өөрчлөх зүйлс (src/config.js)

| Юуг | Хаана |
| --- | --- |
| Нэвтрэх бичиг, товчны бичиг | `text` |
| Толгой дээрх нэр | `names` |
| Бялуутай ширээний байрлал | `table.position` |
| Салютаар бичигдэх мэндчилгээ, өнгө | `message` (`wide` нь компьютер, `tall` нь утас) |
| Энхжингийн үс, арьс, хувцасны өнгө | `characters.enkhjin` |
| Чиний character | `characters.me` |
| Үсний загвар | `hairStyle`: `pigtails`, `long`, `bun`, `short` |
| Хувцас | `outfit`: `dress`, `shirt` |
| Үсний гоёл | `accessory`: `bow`, `none` |
| Бялууны өнгө | `cake` |
| Чиний байрлал, сандлын байрлал | `me.position`, `bench.position` |
| Хэр ойртоход ending эхлэх | `interactionRadius` |
| Ending эхлэхээс өмнө заавал алхах зай | `minWalkDistance` |
| Энхжингийн хурд | `player.speed` |
| Салютын өнгө | `fireworks.colors` |
| Мод, цэцгийн байрлал | `world.seed` тоог өөрчил |

Харилцан ярианы бүх үгийг `src/story.js` дотроос өөрчилнө. Энхжингийн сонголт бүр яг хоёр хариулттай.

Төгсгөлийн хугацааг өөрчлөх бол `src/ending.js` доторх `await wait(секунд)` тоонуудыг сольно.

## 4. Дуу

Одоогоор browser дотор синтезээр үүсгэсэн дуу тоглоно: өөрийн зохиосон энгийн хөгжмийн хайрцаг аялгуу, салютын тэсрэлт (хурц тачигнал, гүн нүргээн, шажигнах оч, задгай тэнгэрийн цуурай), хөөрөх исгэрэлт, уулзах үеийн хонх. Салют дэлгэцийн аль талд дэлбэрнэ, дуу нь тэр чихэнд илүү сонсогдоно. Чихэвчээр сонсвол хамгийн гоё. Copyright-той дуу огт ашиглаагүй.

Өөрийн дуугаа хэрэглэх бол `assets/audio/` дотор яг эдгээр нэрээр тавихад л автоматаар солигдоно:

| Файл | Юу | Урт | Хэмжээ |
| --- | --- | --- | --- |
| `music.mp3` | Арын хөгжим (loop) | 1 ээс 3 мин | 4 MB аас бага |
| `firework.mp3` | Салют дэлбэрэх | 1.5 аас 3 сек | 200 KB аас бага |
| `launch.mp3` | Салют хөөрөх | ойролцоогоор 1 сек | 100 KB аас бага |
| `interaction.mp3` | Уулзах үеийн хонх | 1 сек хүртэл | 100 KB аас бага |
| `big-firework.mp3` | Төгсгөлийн том зүрхэн салют | 3 аас 5 сек | 400 KB аас бага |

Формат нь MP3, 44.1 kHz, 128 эсвэл 192 kbps. Дууны чанга сулыг `config.js` доторх `audio.volume`-аас тохируулна.

Анхаарах: iPhone-ий хажуугийн чимээгүй (silent) товч асаалттай бол browser-ийн дуу гарахгүй. Энхжинд утасныхаа дууг асаагаарай гэж хэлээрэй.

## Салютын төрлүүд

Бодит салют шиг пуужин газраас "түг" хийн хөөрч, 2 орчим секундын дараа оргил цэгтээ дэлбэрнэ. Алсын салютын дуу гэрлээсээ хоцорч сонсогдоно. Од нь агаарт удааширч, аажмаар унаж, шатаж дуусна. Шоунд дараах төрлүүд холилдон буудна:

| Нэр | Ямар харагддаг |
| --- | --- |
| peony | Жигд бөмбөрцөг, дотроо өөр өнгийн цөмтэй |
| chrysanthemum | Од бүр оч цацруулан ул мөр үлдээнэ |
| willow | Алтан бургас: урт унжсан алтан ул мөр, 5 секунд орчим |
| kamuro | Өтгөн алтан титэм |
| palm | Далдуу мод шиг цөөн бүдүүн алтан мөчир |
| crossette | Од бүр хагас замдаа дахин 4 хуваагдана |
| multibreak | Дэлбэрээд, дотроос нь жижиг бөмбөгүүд дахин дэлбэрнэ |
| crackle | Шатаж дуусахдаа тачигнан хагарна |
| strobe | Мөнгөлөг од анивчина |
| ring | Цагираг |
| colorchange | Од шатах явцдаа өнгөө солино |
| salute | Хүчтэй цагаан гялбаа, чанга буу |

Мөн хос салют, сэнс шиг ар араасаа буудах жижиг салют, алтан бургасны хөшиг зэрэг дараалал бий. Төрөл, давтамжийг `src/fireworks.js` доторх `SHELL_TYPES` ба `_nextPattern` хэсгээс өөрчилнө.

## 5. Public link болгож deploy хийх

Static файлууд учраас аль ч үнэгүй static hosting дээр байрлуулж болно.

### Хамгийн хялбар: Netlify Drop (бүртгэлтэй, 1 минут)

1. https://app.netlify.com/drop руу орно.
2. `Enkhjin` хавтсаа бүхэлд нь чирээд тавина.
3. `https://random-name.netlify.app` маягийн link гарна. Site settings дотроос нэрийг нь `enkhjin-birthday` гэх мэтээр сольж болно.

### GitHub Pages

1. GitHub дээр шинэ repository үүсгэнэ (жишээ нь `enkhjin`).
2. Энэ хавтсын файлуудыг тэр repository руу upload хийнэ (`index.html` нь хамгийн гадна талд байх ёстой).
3. Repository дээр Settings, дараа нь Pages цэс рүү орж Source: `Deploy from a branch`, Branch: `main`, хавтас `/ (root)` сонгоод Save.
4. 1, 2 минутын дараа `https://ТАНЫ-НЭР.github.io/enkhjin/` link ажиллана.

### Vercel

```bash
npx vercel
```

Асуултуудад Enter дарахад л хангалттай. Framework асуувал `Other` сонгоно.

Deploy хийсний дараа link-ээ өөрийн утсан дээр заавал нэг удаа бүтэн тоглож шалгаарай. 

## 6. 3D model, texture, font (дараа нь сайжруулах бол)

Одоогийн хувилбарт model файл огт хэрэггүй. Хэрэв дараа нь Blender гэх мэт программаар хийсэн жинхэнэ model оруулъя гэвэл ийм байх хэрэгтэй:

| Зүйл | Шаардлага |
| --- | --- |
| Формат | `.glb` (glTF 2.0 binary, texture нь дотроо багтсан) |
| Нэр | `assets/models/enkhjin.glb`, `assets/models/me.glb`, `assets/models/cake.glb` |
| Хэмжээ | Нэг файл 2 MB аас бага, 5000 аас бага triangle |
| Өндөр | Ойролцоогоор 1.8 unit (одоогийн character-тэй ижил) |
| Төв цэг | Хөлний ул дээр (0, 0, 0) |
| Чиглэл | Нүүр нь +Z тал руу харсан |
| Анимэйшн | `Idle`, `Walk`, `Sit`, `Cheer` гэсэн нэртэй |
| Texture | 512 эсвэл 1024 px, PNG эсвэл JPG |

Model оруулах үед `src/character.js` доторх `Character` class-ийг GLTFLoader ашигладаг хувилбараар солих шаардлагатай. Энэ нь кодын өөрчлөлт тул model бэлэн болсон үед тусад нь хийнэ.

Font: одоогоор Google Fonts-оос Comfortaa (кирилл үсэгтэй) ачаалж байна. Салютын бичиг ч мөн энэ font-оор зурагдана. Интернэтгүй үед ч ажиллуулах бол `.woff2` файлуудыг `assets/fonts/` дотор тавиад `style.css`-д `@font-face` нэмнэ.

## 7. Технологи

* Three.js r160 (CDN, build алхам шаардлагагүй)
* Энгийн JavaScript ES modules
* Web Audio API
* Гүйцэтгэл: instanced mesh, blob сүүдэр, нэг Points дотор бүх салют. Утас удаан бол pixel ratio автоматаар буурна
* Дасан зохицох: босоо болон хэвтээ утас, iPhone-ий notch (safe area), утас эргүүлэх, хаягийн мөр нуугдах үед хэмжээ автоматаар тохирно
* Нэвтрэх: link нээмэгц "Дэлхий үүсэж байна" гэж гарч, camera тэнгэрээс бууж, Энхжин төрж гарч ирнэ. Дуу анхны хүрэлтээр асна (утас дуу автоматаар тоглуулахыг зөвшөөрдөггүй)
* Хамгаалалт: дүр нэг секунд урагшлахгүй бол тэр цэгийг алгасна, тиймээс хэзээ ч гацахгүй. 3D дэмжихгүй browser эсвэл интернэт удаан үед тайлбар гарна
